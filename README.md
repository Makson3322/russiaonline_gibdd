## 💻 О проекте

**dalvvhelp** — приложение для удобной работы с инструментами и функциями проекта в одном месте.

Проект развивается, получает обновления и улучшения для повышения удобства использования.

- 🎯 Удобный графический интерфейс
- ⚡ Быстрый доступ к функциям приложения
- 🖥️ Работа в Windows

- 🎨 Современный интерфейс

## 📦 Установка

1. Скачайте **AutoHotkey v1.1.37.02** — он необходим для запуска приложения.
2. Запустите установщик AutoHotkey и завершите установку.
3. Скачайте файл **dalvvhelp v5.0.5**.
4. Запустите `pom.ahk`.
5. Приложение готово к использованию.
